# EduMind AI

**AI-Powered University Intelligence and Analytics Platform**

EduMind AI is an educational technology project designed to help universities analyse institutional data, understand academic performance, identify students who may benefit from support, and improve decision-making through data science, machine learning, artificial intelligence, and Power BI.

## Project Objectives

- Analyse university data using Python and SQL.
- Develop and evaluate machine learning models.
- Build interactive Power BI dashboards.
- Explore AI-assisted reporting and institutional data queries.
- Provide a foundation for a secure university management and analytics platform.

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- Jupyter Notebook
- Power BI
- SQL and PostgreSQL (planned)
- FastAPI (planned)

## Project Status

**Version 0.1.0 — Initial setup**

The development environment and initial project structure are being established. Data analysis, predictive modelling, dashboards, and AI features will be added incrementally.

## Responsible Use

The initial development will use synthetic or appropriately licensed sample data. Real student records must not be uploaded to this repository. Academic predictions are intended to support human decision-making, not replace it.
